환경광 / HDRI

HDRI 미설정 · 로컬 파일을 업로드하면 프로젝트 ZIP에도 포함됩니다.

기본 모드는 실제 HDRI 사진이 아닌 환경광 프리셋입니다. .HDR 파일을 업로드해야 사진 기반 환경 반사를 사용합니다.

작품 재질 / 명시적 변경

원본 파일의 재질과 텍스처를 그대로 유지 중입니다.

적용 시 작품에만 별도 렌더 재질을 사용합니다. 현장 모델·원본 작품 파일을 수정하지 않으며, MASTER LOCK 후 변경할 수 없습니다.

카메라 / 시점

렌즈 값은 카메라 화각만 변경하며 작품의 크기와 위치는 유지합니다.

예상 출력 크기 계산 중

렌더 시 그리드·조작 기즈모·태양 위치 표시는 제외됩니다. GPU 한계를 넘는 설정은 자동 축소합니다. Blender Cycles나 이미지 생성 AI 실사화는 아닙니다.
