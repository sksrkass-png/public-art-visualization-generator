📚 MASTER VERSION HISTORY

다른 기기와 협업하려면 검토 요청이 포함된 전체 프로젝트 ZIP과 검토 JSON을 전달하세요. 수정 요청 후에는 새 MASTER Revision을 만들고 재검토합니다. SHA-256은 변경 비교용 지문이며 사용자 신원·법적 승인 인증이 아닙니다. 실시간 동기화 기능은 제공하지 않습니다.

MASTER 승인 후 사용 가능

작성자·의견을 입력한 뒤 승인 MASTER의 표면을 클릭하세요.

핀 위치는 해당 MASTER 당시의 3D 월드 좌표(m)입니다. 다음 Revision에서는 이전 핀을 표시하지 않고 기록만 보존합니다. 전체 프로젝트 ZIP과 설정 JSON에 함께 저장되며, 구조 안전·현장 실측·작성자 신원 검증을 대신하지 않습니다.

💾 프로젝트 저장

v1.0은 SHA-256 무결성 정보까지 함께 저장하고 ZIP 복원 전에 손상 여부를 검증합니다. 구형 프로젝트 ZIP도 불러올 수 있습니다. SHA-256은 파일 손상 확인이며 작성자 인증은 아닙니다.

JSON은 설정만 저장하는 기존 방식으로 유지합니다. 모델 복원에는 위 ZIP을 이용하세요. GLB는 3D 메시 내보내기용입니다.
